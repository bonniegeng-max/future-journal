# 未来日记 · Future Journal

未来日记是一个**每天三分钟**的书写工具 skill。它不管过去发生了什么，只做一件事：
让用户先描一句引导句，再用**过去时**写下今天希望发生的事，最后挑一个心情词。

49 天为一轮，每周换一个主题。既能当电子手账填写，也能打印出来用实体本子写。

> ⚠ **这不是《三分钟未来日记》的官方产品。** 方法与实践节奏受山田弘美、滨田真由美所著的
> 日记实践书启发，但本工具**未使用书中任何正文内容**，49 句引导句全部为原创。
> 书名仅用于说明方法来源。

当前版本 **v1.0.4**。

> **语言范围**：**默认简体中文（zh-CN）**，英文双语说明随包提供。界面与文档以中文为
> 第一语言，因为「未来日记」的语感、过去时句式、心情词都建立在中文上。
> **用户书写内容不限语言**（中英文皆可）；字体栈按中英双语定义，西文回退
> `Georgia` / `-apple-system`。需要其他语言的界面或句库可向作者提出。
> 英文能力摘要见 `skill-card.md`。
>
> *Language scope: default locale is Simplified Chinese (`zh-CN`) with English
> documentation bundled (`skill-card.md`). User entries are not language-restricted —
> write in Chinese or English. Font stacks are bilingual. Other locales on request.*

## 它能做什么

### 1. 给出一本可以立刻用的电子手账

`assets/index.html` 是一个**单文件页面**——没有构建步骤，核心功能不依赖任何外部资源，
复制到任何位置双击就能打开。手机浏览器同样可用。

唯一会碰网络的是**可选的云同步**：只有你自己粘了配置串、且页面从 `http(s)://` 打开时，
才会下载一份同步组件。不配同步就一个请求都不发。

它包含四个页面：

| 页面 | 作用 |
|---|---|
| 今日 | 描摹 / 打字过一遍引导句 → 用过去时写一句话 → 挑心情词 |
| 轨道 | 7×7 共 49 格的进度网格，一眼看到走到哪一格 |
| 回顾 | 按周回看写过的内容（满 7 天才解锁上一周） |
| 设置 | 导出 / 导入备份、开始新的一轮、可选的跨设备同步 |

### 2. 回答「今天写哪一句」

```bash
node scripts/today.js 2026-09-17           # 以该日期为第 1 天，算到今天
node scripts/today.js 2026-09-17 --day 8   # 直接指定第几天
```

用户想写在实体本子上时用这个——不用打开网页也能拿到当天的句子。

### 3. 维护 49 句原创引导句库

句库内嵌在页面里，改完必须过质量闸门：

```bash
node scripts/check-prompts.js
```

检查项：7 周 × 7 句的结构、重复句、将来时标志词、句末情绪词、单句长度 ≤ 30 字。

新句子的公式：**时间锚点 + 一件具体的好事 + 完成态 + 句末情绪词**

- ✅ `今天的活一件件推进了，我很安心。`
- ❌ `我希望今天工作顺利。` ← 将来时，方法明确要求写过去时

> 中文没有时态标记，肉眼判断「是不是过去时」极不可靠，所以闸门脚本用
> **禁止将来时标志词**这条硬规则兜底。

### 4. 可选的跨设备同步（默认关闭）

不登录 = 纯本地，功能一个不缺。只有用户**自己粘贴配置串**并登录之后，
才会开启「端到端加密」的跨设备同步：

- 加密在浏览器里完成（PBKDF2 20 万次 → AES-GCM-256），**服务器只存密文**
- 同步密码丢了，云端那份就打不开，本机记录不受影响
- 配置串必须使用者自备，**页面里没有任何硬编码的服务器地址或密钥**
- **换设备**：新设备会停在「开始这一轮」落地页 —— 不用先硬开一轮，
  那里就有「去开启同步」入口（底部 tab 栏要等这一轮开始后才出现，所以旁边另给了回头路）。
  同步时起始日取两边**较早**的那个，新设备上开过的日期不会把进度带偏

## 隐私边界

| 行为 | 何时发生 | 去向 | 传了什么 |
|---|---|---|---|
| 下载云同步 SDK | **仅当**使用者自己粘贴了配置串，且页面从 `http(s)://` 打开 | `cdn.jsdelivr.net` | 只下载代码，不上传。**版本已钉死到具体版本号并带 SRI 完整性校验**——CDN 上的字节被改动，浏览器直接拒绝执行 |
| 发验证码 / 维持登录态 | 使用者主动点登录 | 使用者**自己配置的**后端 | 邮箱、会话令牌（会离开设备） |
| 上传日记 | 使用者设了同步密码之后写入内容 | 使用者**自己配置的**后端 | **只有密文** |

这个表以外没有别的：无统计、无埋点、无第三方字体 / 图标 CDN、无硬编码密钥。
不配同步时页面从 `file://` 打开，**一个网络请求都不发**。

> 为什么 SDK 要钉版本 + 校验完整性：这段远端代码和页面同源执行，能读到 localStorage 里的
> 日记正文和导出的加密密钥。用一个会漂移的版本标签（如 `@dev`）意味着「审核时的那份代码」
> 和「用户实际执行的那份」可以不是同一份。改 SDK 版本时必须同步重算 SRI 哈希，
> 回归测试 D 组会卡住这一步。

- 默认数据只存在用户浏览器的 localStorage（键名 `future-journal-v1`），skill 读不到
- 清缓存 / 换浏览器，本机数据就没了——localStorage 的固有特性
- 「设置」里有导出 / 导入，备份是整包 JSON

## 一些刻意的设计决定

- **回看是延迟解锁的**：满 7 天才打开上一周。方法本身建议不要天天回头翻
- **「过一遍」有两种方式，都不该被拿掉**：有触控笔走「用笔描」（canvas，只记笔迹，
  不判对错）；鼠标 / 触控板走「照着打一遍」（照着灰字逐字输入）。
  触控板描摹是手眼分离，实测无法控制——打字模式不是可选项，是必需项
- **写作框自动落盘**：不需要点保存按钮，切页面 / 刷新都不会丢
- **输入框字号锁 16px**：低于此值会触发 iOS Safari 自动缩放
- **无障碍按 WCAG 2.2 AA 做**：正文对比度 ≥ 4.5:1、键盘可完成全流程、焦点可见、
  状态不靠单一颜色传达。唯一豁免是描摹引导字——它是「盖着描的底稿」不是正文，
  等价路径已在打字模式和打印版里备好。详见 `references/DESIGN.md` 附录 A

## 它不做什么

- **不默认开同步**，不做打卡羞辱、不做断更提醒
- **不做推送提醒**（页面关闭即止，做不到）。想每天被提醒，用 Agent 平台的定时任务
- **不做暗色模式**（纸质手账没有暗色版）
- **不引入任何第三方图标库、字体 CDN、统计脚本**——离线可用是硬要求
